Pangan

A free, open-source focus timer with a Persian calendar and a focus journal — built with Rust & Slint, available on desktop and mobile.

Native • Lightweight • Single binary Open source • MIT
Download View on GitHub

Available on

Linux Windows macOS Android iOS (simulator)

Features

Focus timer

Customizable Pomodoro sessions with a calm, circular progress ring.

Persian calendar

Jalali dates, Iranian historical events, and Sasanian day names.

Daily tasks & rota

Connect each focus session to real intentions and a daily plan.

Focus journal

Weekly digests that reflect on outcomes, not just minutes counted.

Statistics

Productivity trends across sessions, hours, and metrics.

Historical themes

Cyrus, Darius, Parthian, and Sasanian visual styles.

Cloud sync

Optional Google Drive synchronization and backup/restore.

Personalized

Light/dark appearance, English/Persian, and Iranian procedural sounds.

Install

Download the latest build for your platform from the releases page, or build from source:

git clone https://github.com/DariushKhosrowan/pangan.git
cd pangan
cargo build --release
./target/release/pangan

Checksums are provided for every release asset via SHA256SUMS.txt.

Why Pangan?

Pangan (پنگان) is the Persian word for an ancient water clock used to divide time fairly among people. A fitting ancestor for a focus timer — small, precise, and fair to your attention.
