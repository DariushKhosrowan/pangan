Build from source

# Requires Rust toolchain
git clone https://github.com/DariushKhosrowan/pangan.git
cd pangan
cargo build --release
./target/release/pangan

A one-command installer for Linux and Windows is also included in the repository (packaging/).

Release assets & checksums

Every release ships verified SHA256SUMS.txt checksums. Current asset filenames:

  • Linux — pangan-linux-x86_64, pangan-linux-aarch64
  • Windows — pangan-windows-x86_64.exe, pangan-windows-aarch64.exe
  • macOS — pangan-macos-x86_64, pangan-macos-arm64
  • Android — pangan-android-universal.apk
  • iOS simulator — pangan-ios-simulator.app.zip
