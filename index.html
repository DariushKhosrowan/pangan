Pangan

A minimal, efficient Pomodoro timer for Linux, Windows & macOS — Rust + Slint, ~4–8 MB idle RAM.

Native • Lightweight • Single binary
View on GitHub Download

Features

System tray

Live countdown with Start/Pause, Skip, Reset, Quit from the tray menu.

Notifications

Desktop notification when each focus/break session ends.

Global hotkey

Super+P to start/pause from anywhere.

Stay awake

Inhibits screen lock/suspend during focus sessions.

Autostart

Launches at login via a .desktop entry.

Configurable

Work/break lengths set in ~/.config/pangan/config.toml.

Install

git clone https://github.com/amirhosseineslami/pangan.git
cd pangan
cargo build --release
./target/release/pangan &   # autostarts on next login

Why Pangan?

Pangan (پنگان) is the Persian word for an ancient water clock used to divide time fairly among people. A fitting ancestor for a focus timer — small, precise, and fair to your attention.
